# 📬 InstantMail Hub - بريد إنستانت

تطبيق ويب عصري وسريع لتوليد وإدارة البريد الإلكتروني المتعدد مع حفظ دائم للحسابات واستخراج تلقائي لأكواد التفعيل (OTP).

## ✨ المميزات
- ⚡ إنشاء فوري للإيميلات (عشوائي أو باسم مخصص).
- 💾 تخزين دائم لجميع الحسابات وكلمات المرور.
- 🔑 استخراج وتظليل فوري لأكواد التحقق والتفعيل (OTP Detection).
- 🔄 تحديث تلقائي للرسائل كل 5 ثوانٍ.
- 📱 واجهة متجاوبة وأنيقة تدعم اللغة العربية.
- 🐳 دعم Docker و Render و Railway و Koyeb للنشر السحابي المجاني.

## 🚀 التشغيل السريع
```bash
node server.js
```
ثم افتح المتصفح على: `http://localhost:3333`
